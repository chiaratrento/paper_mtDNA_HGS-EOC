# Pathway category tables

Used only to colour/filter pathways by category in the figures.

- `kegg_final.txt`: KEGG pathway ID → top-level category (`Main`, e.g. "1. Metabolism") and sub-category (`Second`), whitespace-separated.
- `reactome_final.txt`: Reactome pathway ID → top-level group (`Group`, e.g. "Metabolism").
