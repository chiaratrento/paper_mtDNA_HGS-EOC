# Homoplasmic mitochondrial DNA variants associate with favorable prognosis in high-grade serous ovarian cancer

This repository contains the analysis code supporting Trento et al., *"Homoplasmic mitochondrial DNA variants associate with favorable prognosis in high-grade serous ovarian cancer"*, submitted to the International Journal of Cancer (IJC).

It is provided in response to the editorial requirement that computational tools/code used for data and statistical analysis be made publicly available.

## Repository structure

```
.
├── R/
│   ├── 01_preprocessing_notes.md        # FastQC/MultiQC/cutadapt/Salmon pipeline (shell, not R)
│   ├── 02_import_and_QC.R               # tximport, count filtering, sample QC (PCA, RLE, normalization comparison)
│   ├── 03_DESeq2_differential_expression.R  # DESeq2 design formula(s), DEG thresholds, WT vs MUT contrast
│   └── 04_enrichment_analysis.R         # ORA (enrichGO, enrichKEGG, enrichPathway) and GSEA (gseGO, gseKEGG, gsePathway)
├── metadata/
│   └── sample_metadata_description.md   # Description of clinical/technical variables used as covariates (no patient-identifiable data)
├── results/                             # Summary tables and figures generated by the scripts above
└── README.md
```

## Analysis pipeline

1. **Sequencing & preprocessing** — 150 bp paired-end reads, Illumina platform. Quality control with FastQC and MultiQC; adapter/quality trimming with cutadapt.
2. **Alignment & quantification** — Pseudoalignment and transcript quantification with Salmon against the GENCODE GRCh38.p13 human reference; gene-level count aggregation with `tximport`.
3. **Differential expression** — `DESeq2`, with genes filtered at `rowMeans(counts) >= 10` prior to testing. DEGs defined as `padj < 0.05` and `|log2FoldChange| > 0.6`. Design compares WT vs MUT (`~ comp_3`).
4. **Sample QC** — PCA (rlog/vst transforms), RLE plots, and comparison of normalization methods (upper-quartile, full-quantile, TMM, RLE) to assess outliers and unwanted technical variation.
5. **Pathway enrichment** — Over-representation analysis (`clusterProfiler::enrichGO`, `enrichKEGG`, `ReactomePA::enrichPathway`) and GSEA (`gseGO`, `gseKEGG`, `gsePathway`) on GO (BP/CC/MF), KEGG, and Reactome gene sets.

## Software requirements

R (≥4.5) with the following key packages: `DESeq2`, `tximport`, `edgeR`, `EDASeq`, `clusterProfiler`, `ReactomePA`, `org.Hs.eg.db`, `pathview`, `sva` and/or `RUVSeq` (batch/unwanted-variation estimation), `ggplot2`, `pheatmap`, `DEGreport`.
